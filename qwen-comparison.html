⚠️ Précision importante

Qwen ne se connecte pas "magiquement" à GitHub. Vous devez :

  • 1. Copier-coller votre code dans le chat
  • 2. Utiliser un plugin/CLI qui envoie le contexte via API
  • 3. Configurer un webhook GitHub → API Qwen
